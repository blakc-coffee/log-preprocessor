# Universal Log Pre-processing Framework (ULPF)
**SIH 2026 Problem Statement ID:** SIH26156  
**Sponsoring Agency:** National Technical Research Organisation (NTRO)  
**Theme:** Blockchain & Cybersecurity / Systems Engineering  

## Overview
ULPF is a high-throughput, sovereign, air-gap-compliant log pre-processing engine featuring:
- **Data Plane (Go):** High-speed ingestion, content-addressed vaulting with Merkle trees, and render-back verification.
- **Intelligence Plane (Python):** Drain3 log template mining, drift detection, and automated parser proposals.
- **Control Plane (Go + React):** Review queue, audit registry, and byte-exact forensic lineage explorer.
